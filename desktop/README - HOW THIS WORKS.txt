==========================================================
   KJM GPS CONDITIONS
   Is today a good day to run GPS?
==========================================================

TO USE IT (every computer, every time):

   Double-click:   Launch KJM GPS Conditions.vbs

   That one click does everything:
     - Puts a "KJM GPS Conditions" icon on your Desktop
       (first time only - after that just use the icon).
     - Opens the dashboard in your web browser.
     - Picks up new versions by itself when Dropbox brings them.

   That's it. Nothing else in this folder needs touching.


WHAT IT SHOWS:

   An A-F grade for today's GPS work (RTK, drone, ag, navigation),
   hour by hour for 3 days and a 45-day outlook, built from live
   NOAA space-weather data and the satellites over your job site.
   Learn mode (on by default) explains every part in plain words.
   Set your job site with the pin button at the top.


WHAT'S IN THIS FOLDER:

   Launch KJM GPS Conditions.vbs  <- the only button you need
   README - HOW THIS WORKS.txt    <- this file
   app\                           <- the program itself (leave alone)
   help\                          <- notes for whoever maintains it


IF IT WON'T OPEN:

   1. Make sure Dropbox shows a green check on this folder
      (still syncing = files missing).
   2. Python must be installed once per computer - get it at
      python.org and check "Add Python to PATH", or run
      Dropbox\Apps\_APP STANDARD\FIX - Install Python (one click).cmd
   3. It needs the internet: the data comes from NOAA, NASA and
      CelesTrak every few minutes.
   4. Still stuck? Look in the help\ folder.
==========================================================
